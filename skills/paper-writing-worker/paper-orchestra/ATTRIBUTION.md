This prompt module adapts workflow ideas from:

- Ar9av/PaperOrchestra: https://github.com/Ar9av/PaperOrchestra
- Song et al., "PaperOrchestra: A Multi-Agent Framework for Automated AI Research Paper Writing", arXiv:2604.05018

The local implementation is not a verbatim copy of the upstream runtime. It maps the PaperOrchestra workflow into this repository's existing paper-writing-worker boundary and deterministic tool surface.
