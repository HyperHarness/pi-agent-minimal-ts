# Single Xmon Concept Layout

This experiment contains a conceptual single-Xmon/transmon KLayout generator and its generated GDSII layout.

## Files

- `code/single_xmon_concept_klayout.py`: KLayout Python script that generates a conceptual single-Xmon layout.
- `layouts/single_xmon_concept.gds`: generated GDSII stream from the script.

## Scope

This is a concept artifact for design discussion and knowledge-base retrieval. It is not fabrication-ready and has not been checked against a foundry PDK, process-specific layer map, junction cell, DRC deck, EM simulation, packaging constraints, or low-temperature validation data.
